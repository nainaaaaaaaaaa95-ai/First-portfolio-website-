## 📌 About the Project

This project marks my first step into the world of Web Development. It is my first-ever website, created to explore the fundamentals of designing and developing websites using basic web technologies.

The main purpose of this project was to understand how websites are structured, styled, and made interactive. While building this website, I explored different HTML elements, CSS styling techniques, page layouts, and basic design concepts.

This project represents the beginning of my web development journey and helped me build confidence in turning ideas into a functional website.

* Understand the fundamentals of website development.
* Learn how HTML structures web pages.
* Explore CSS for styling and designing layouts.
* Develop an understanding of website navigation.
* Gain practical experience in creating a website from scratch.
* Improve creativity and problem-solving skills.

## 🛠️ Technologies Used
